## 1. Interactive Web Funnels & Landing Pages

| File | Description | Key Features |
| :--- | :--- | :--- |
| **`index.html`** / **`sales_page.html`** | Flagship direct-response sales page | Live fuel vs. solar savings calculator, video container, dynamic model switcher, WhatsApp direct checkout |
| **`affiliate.html`** | Official Affiliate Program portal | 5%–12% commission tier calculator, instant flyer asset downloads, onboarding FAQs |
| **`partner_onboarding.html`** | Partner Onboarding & Recruitment Hub | Split-track funnel for zero-capital affiliates and stocking wholesale distributors (up to 22% margin) |

### Testing Pages Locally
To run the local server on Windows PowerShell:
```powershell
.\server.ps1
```
Then navigate to `http://localhost:8080/` in your browser.

## 3. Copywriting & Sales Enablement Bibles

- **`LUMEY_EXHAUSTIVE_LONGFORM_SALES_COPY_BIBLE.md`**: Complete, battle-tested long-form sales copy with pain-agitation-solution hooks grounded in Nigeria's fuel cost reality (₦1,050–₦1,250/L petrol and Band A tariffs).
- **`Lumey_All_Models_Master_Sales_Copy_Angles.pdf`**: Detailed audience avatars (remotely employed tech workers, pharmacy/cold-chain owners, bar/restaurant operators, salon/barbershop owners).
- **`LUMEY_AFFILIATE_MASTER_PROMOTIONAL_COPY_BIBLE.md`**: Ready-to-deploy WhatsApp status updates, broadcast sequences, direct outreach scripts, and social media hooks for partners.
